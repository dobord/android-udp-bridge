### 🏗️ Архитектурные улучшения

#### Структуры данных
```c
struct ssh_session_struct {
    int socket_fd;              // Реальный TCP сокет
    int timeout;                // Настраиваемый таймаут
    int log_verbosity;          // Уровень логирования
    int strict_host_key_check;  // Проверка ключей хоста
    char error_msg[256];        // Детальные сообщения об ошибках
};

struct ssh_key_struct {
    enum ssh_keytypes_e type;   // Тип ключа (RSA/DSA/ECDSA/Ed25519)
    unsigned char* key_data;    // Данные ключа
    size_t key_length;          // Размер ключа
};
```

#### API расширения
- `ssh_is_connected()` - проверка статуса соединения
- `ssh_key_type()` - определение типа ключа
- `ssh_key_type_to_char()` - преобразование типа в строку
- `ssh_channel_is_eof()` - проверка состояния канала
- `sftp_new()`, `sftp_init()` - базовая SFTP поддержка
