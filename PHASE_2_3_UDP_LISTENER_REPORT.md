- `udp_listener_send_to_client()` - отправка данных клиенту

**Возможности:**
- Асинхронная обработка UDP пакетов в отдельном потоке
- Автоматическая идентификация и регистрация клиентов
- Интеграция с протоколом bridge для передачи данных
- Сбор статистики по пакетам и клиентам
- Thread-safe операции с мьютексами

## Архитектурные улучшения

### 1. Threaded UDP Processing
UDP listener работает в отдельном потоке, что обеспечивает:
- Неблокирующую обработку UDP пакетов
- Независимость от основного SSH туннеля
- Возможность обработки множественных клиентов

### 2. Protocol Integration
Каждый UDP пакет теперь:
- Ассоциируется с уникальным client_id
- Упаковывается в протокольное сообщение MSG_DATA
- Передается через TCP соединение к bridge серверу
- Отслеживается в статистике

### 3. Client Management
Система управления клиентами обеспечивает:
- Автоматическую регистрацию новых клиентов
- Отслеживание активности и таймаутов
- Мониторинг статистики передачи данных
