# Новый UI интерфейс приложения UDP Bridge

## Обзор изменений

Пользовательский интерфейс приложения был полностью переделан согласно требованиям:

### 1. Упрощенный главный экран

**Большая круглая кнопка подключения:**
- Размер: 200x200dp
- Отображает статус подключения прямо в тексте кнопки:
  - "Connect" - когда отключено
  - "Connected" - когда подключено
- Цвет меняется в зависимости от состояния:
  - Золотисто-оранжевый (golden_apricot) - для подключения
  - Красный (vibrant_red) - когда подключено

**Информация под кнопкой:**
- Отображает статус туннеля и статистику
- "Ready to connect" - в состоянии готовности
- "Tunnel Established" - при активном подключении
- Детальная информация о настроенном форвардинге

### 2. Выбор сервера

**Выпадающий список серверов:**
- Расположен под основной кнопкой подключения
- Показывает список сохраненных конфигураций серверов
- Отображается либо пользовательское название сервера, либо "ip:port"
- Автоматически запоминает последний выбранный сервер

**Кнопка добавления сервера (+):**
- Маленькая круглая FAB кнопка рядом с выпадающим списком
- Открывает экран создания новой конфигурации сервера

### 3. Вынесенные элементы

Все сложные настройки перенесены в отдельные экраны:

**Кнопка "Settings":**
- Открывает экран редактирования выбранного сервера
- Содержит все SSH настройки, bridge настройки и UDP форвардинг

**Кнопка "Bridge Settings":**
- Открывает существующий экран настроек UDP Bridge

## Новые компоненты

### ServerConfig (модель данных)
```java
- id: long - уникальный идентификатор
- name: String - пользовательское название
- sshHost, sshPort, username - SSH параметры
- password/privateKey + passphrase - аутентификация
- bridgeEnabled, bridgeHost, bridgePort - настройки моста
- localPort, remoteHost, remoteUdpPort - UDP форвардинг
- autoReconnect, connectionTimeout - дополнительные опции
```

### ServerConfigManager
- Управление списком конфигураций серверов
- Сохранение в SharedPreferences через Gson
- Запоминание последнего выбранного сервера

### ServerConfigActivity
- Полноэкранная форма для создания/редактирования сервера
- Все настройки в удобном интерфейсе с валидацией
- Поддержка как password, так и private key аутентификации

## Преимущества нового UI

1. **Простота использования:** Главный экран содержит только самое необходимое
2. **Быстрое переключение:** Легко переключаться между сохраненными серверами
3. **Упорядоченность:** Сложные настройки вынесены в отдельные экраны
4. **Статус в реальном времени:** Состояние подключения видно сразу на кнопке
5. **Управление конфигурациями:** Возможность сохранять множество серверных настроек

## Совместимость

Новый UI полностью совместим с существующими сервисами:
- SshTunnelService - без изменений
- UdpBridgeService - без изменений  
- UdpBridgeConfigActivity - остается как есть

Скрытые элементы старого UI сохранены для совместимости с существующим кодом.

## Файлы изменений

### Новые файлы:
- `models/ServerConfig.java` - модель конфигурации сервера
- `models/ServerConfigManager.java` - менеджер конфигураций
- `ServerConfigActivity.java` - экран настройки сервера
- `layout/activity_server_config.xml` - layout для настройки сервера
- `menu/server_config_menu.xml` - меню с кнопкой сохранения

### Измененные файлы:
- `layout/activity_main.xml` - новый упрощенный главный экран
- `MainActivity.java` - адаптация под новый UI
- `values/strings.xml` - новые строковые ресурсы
- `build.gradle` - добавлена зависимость Gson
- `AndroidManifest.xml` - добавлена ServerConfigActivity

### Структура нового layout/activity_main.xml:
```xml
- Header (название приложения)
- Main Connection Section:
  - Большая круглая кнопка подключения (200dp)
  - Текст статуса под кнопкой
- Server Selection Section:
  - Выпадающий список серверов
  - Кнопка добавления (+)
- Quick Actions:
  - Кнопка "Settings" 
  - Кнопка "Bridge Settings"
- Скрытые элементы совместимости
```

Новый интерфейс обеспечивает гораздо более удобный и интуитивный пользовательский опыт, при этом сохраняя всю функциональность предыдущей версии.
