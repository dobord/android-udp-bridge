# UDP Bridge Android App - Modern UI

Современное Android приложение для UDP Bridge с интерфейсом в стиле Amnezia VPN.

## ✨ Новые возможности UI

### 🎨 Дизайн-система
- **Цветовая схема**: Темная тема с акцентами в стиле Amnezia VPN
- **Типографика**: Современные шрифты с правильной иерархией
- **Компоненты**: Material Design 3 с кастомными стилями
- **Анимации**: Плавные переходы и состояния

### 🔗 Цветовая палитра
```
Фоновые цвета:
- Midnight Black: #0E0E11 (основной фон)
- Onyx Black: #1C1D21 (карточки)
- Slate Gray: #2C2D30 (границы)

Текстовые цвета:
- Pale Gray: #D7D8DB (основной текст)
- Muted Gray: #878B91 (вторичный текст)

Акцентные цвета:
- Golden Apricot: #FBB26A (кнопки, активные элементы)
- Vibrant Red: #EB5757 (ошибки, отключение)
- Success Green: #27AE60 (успешные операции)
```

### 📱 Компоненты интерфейса

#### Главный экран
- **Статус-карта**: Показывает текущее состояние подключения
- **Круглая кнопка подключения**: 160dp с анимированными состояниями
- **Карточки настроек**: Группировка настроек по функциональности
- **Адаптивные поля ввода**: Material Design 3 TextInputLayout

#### Настройки сервера
- **SSH конфигурация**: Хост, порт, аутентификация
- **Переключатель методов**: Пароль / Приватный ключ
- **Валидация полей**: Реальное время проверки

#### UDP Bridge настройки
- **Современные переключатели**: Material SwitchMaterial
- **Группировка настроек**: Основные и расширенные
- **Автоматическое переподключение**: Визуальная индикация

#### Расширенные настройки
- **Скрываемые настройки**: Показ/скрытие одним касанием
- **UDP форвардинг**: Локальные и удаленные порты
- **Отладка**: Настройки логирования

### 🎯 Улучшения UX

#### Статусы и индикаторы
- **Цветовая кодировка**: Зеленый (подключен), Серый (отключен), Красный (ошибка)
- **Анимированные переходы**: Плавная смена состояний
- **Контекстные сообщения**: Уведомления в реальном времени

#### Адаптивный интерфейс
- **Скрытие элементов**: Неактивные поля автоматически скрываются
- **Группировка**: Логическое разделение функций
- **Быстрый доступ**: Важные действия всегда видны

#### Доступность
- **Контрастность**: Соответствие WCAG 2.1
- **Размеры касаний**: Минимум 48dp для всех интерактивных элементов
- **Фокус**: Четкая навигация с клавиатуры

## 🛠️ Технические детали

### Архитектура
```
Material Design 3 Components:
├── MaterialButton (кнопки)
├── MaterialCardView (карточки)
├── SwitchMaterial (переключатели)
├── TextInputLayout (поля ввода)
└── CoordinatorLayout (координация layout)

Цветовые ресурсы:
├── colors.xml (палитра цветов)
├── color/ (селекторы состояний)
└── drawable/ (фоновые элементы)

Стили:
├── styles.xml (компоненты и темы)
├── Typography (текстовые стили)
└── Card/Button styles (кастомные стили)
```

### Совместимость
- **Min SDK**: 24 (Android 7.0)
- **Target SDK**: 34 (Android 14)
- **Material Design**: 3 (версия 1.11.0)
- **AndroidX**: Полная поддержка

## 🚀 Сборка и установка

### Требования
- Android Studio Arctic Fox или новее
- JDK 11+
- Android SDK 34
- NDK 26.3.11579264

### Быстрая сборка
```bash
./build_modern_app.sh
```

### Ручная сборка
```bash
cd ssh-tunnel-android-app
./gradlew clean
./gradlew assembleDebug
```
